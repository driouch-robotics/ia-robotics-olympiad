# IA & Robotics Club Olympiad

منصة static تفاعلية وثنائية اللغة لاختبار المشاركين في أولمبياد المعلوميات. مبنية بـ React + Vite، وتشتغل بدون قاعدة بيانات أو تسجيل دخول.

## التشغيل المحلي

```bash
npm install
npm run dev
```

الرابط المحلي:

```text
http://127.0.0.1:5173
```

## بناء نسخة النشر

```bash
npm run build
```

الملفات الجاهزة للنشر تخرج في:

```text
dist/
```

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى repository في GitHub.
2. تأكد أن الفرع الرئيسي اسمه `main`.
3. من GitHub ادخل إلى `Settings` ثم `Pages`.
4. في `Build and deployment` اختار `GitHub Actions`.
5. ادفع أي تغيير إلى `main`، وسيشتغل workflow الموجود في `.github/workflows/deploy.yml`.

## تعديل الأسئلة

قاعدة الأسئلة موجودة في:

```text
src/questions.js
```

كل سؤال فيه المستوى، المجال، نوع السؤال، الاختيارات، الجواب الصحيح، وشرح قصير يظهر بعد الإجابة.

## الملفات الأساسية

- `src/App.jsx`: منطق المنصة والتفاعل والموقت والتنقيط.
- `src/questions.js`: 500 سؤال موزعة على المستويات والمجالات.
- `src/i18n.js`: نصوص الواجهة وترجمة الأسئلة بين العربية والفرنسية.
- `src/styles.css`: التصميم والألوان والتجاوب.
- `public/logo-club.png`: شعار النادي المستعمل في الواجهة.
